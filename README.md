# Stock und Stein · Büro

Installierbare Web-App (PWA) für Angebote und Rechnungen eines Garten- und Landschaftsbaubetriebs.
Dieses Repo enthält nur den fertigen Programmcode. **Es werden keine Daten gespeichert oder übertragen** – alle Kunden-, Angebots- und Rechnungsdaten bleiben ausschließlich auf dem Gerät des Nutzers.
